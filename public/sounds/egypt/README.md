# Egypt — Audio assets

Drop CC0 / licensed audio here. The world references these filenames:

- `ambient.mp3` — looping desert wind/hall bed
- `footsteps.mp3` — short footstep loop on stone
- `torch.mp3` — crackling torch (positional, plays at each torch)
- `wind.mp3` — distant wind (positional, far behind the hall)

All files should be short looping clips, mono preferred for positional sounds
(stereo for ambient/footsteps is fine). Keep each under ~300 KB for fast load.
